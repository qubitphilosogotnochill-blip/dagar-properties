# Dagar Properties – Luxury Real Estate Website

A premium, fast-loading, fully responsive static website for **Dagar Properties**, a premier real estate dealership serving the **Dwarka–Najafgarh** region and surrounding areas of South-West Delhi, India.

---

## 🏛️ Project Overview

- **Dealership:** Dagar Properties
- **Regions Served:** Dwarka, Najafgarh, Kakrola, Palam, Dabri, and surrounding Delhi territories
- **Focus Areas:** Residential Properties, Commercial Spaces, Plots & Land, and Rental Accommodations
- **Core Values:** Professional Guidance, In-depth Local Knowledge, Uncompromising Transparency

## 🛠️ Local Development

To view the website locally:

1. Double click `index.html` to open it in any web browser.
2. Or run a lightweight local HTTP server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
